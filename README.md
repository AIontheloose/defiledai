# DefiledAI

Static-first unrestricted local AI platform.

## Stack

- Next.js
- TailwindCSS
- TypeScript
- Cloudflare Pages
- Static export

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Cloudflare Settings

Framework preset:
